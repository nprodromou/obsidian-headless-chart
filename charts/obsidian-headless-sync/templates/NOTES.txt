obsidian-headless-sync is syncing {{ len .Values.vaults }} vault(s) as device "{{ include "ohs.deviceName" . }}".

Watch the first start (the init container installs the client and links each vault):
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "ohs.fullname" . }} -c prepare -f

Follow one vault's sync:
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "ohs.fullname" . }} -c sync-{{ (first .Values.vaults).name }} -f
{{- if include "ohs.hasGitVaults" . }}

Git-backed vaults are fast-forwarded every {{ .Values.git.intervalSeconds }}s.{{ if .Values.git.statusFile }} Each carries a
{{ .Values.git.statusFile }} note that syncs to your devices and says whether it is current.{{ end }}
Run a pass now, without changing anything:
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "ohs.fullname" . }} -c keeper -- node /app/bin/keeper.mjs --once --dry-run
{{- end }}

Do not run desktop Obsidian Sync for these vaults on a machine that also writes
the same content (for example, a laptop fast-forwarding the same git clone).
Two writers uploading the same changes produce conflict files.
